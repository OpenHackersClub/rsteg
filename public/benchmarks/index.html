Homebrew dropped the steghide package in 2024, and upstream ships no arm64 binary, so the comparison baseline is a native arm64 build of steghide 0.6.0 (build steps in the full report).

Caveats

  • Subprocess overhead is not subtracted. Wall-clock measurements include fork/exec, dynamic linker, and CRT init — i.e. what an interactive user actually experiences.
  • Synthetic PNG cover uses random pixel data, adversarial for DEFLATE. Real-photo PNG numbers land in phase 1.5 (png-photo-* cases); miniz_oxide is ~2–3× faster on natural imagery than on noise.
  • Encryption disabled in this run. The embed-encrypted sub-run measures Argon2id + XChaCha20-Poly1305 overhead separately: ~3–4 ms of AEAD on top for ≤ 100 KB payloads; Argon2id dominates when --password is set (memory-hard KDF, intentionally).
